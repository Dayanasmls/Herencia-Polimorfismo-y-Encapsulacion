# Herencia-Polimorfismo-y-Encapsulacion
# Actividad: Herencia, Polimorfismo y Encapsulamiento

## Descripción

Este proyecto corresponde a una actividad de Programación Orientada a Objetos en JavaScript, realizada para aplicar los conceptos de herencia, polimorfismo y encapsulamiento.

## Herencia

La herencia permite crear nuevas clases a partir de una clase principal. En este proyecto se utiliza `Vehiculo` como clase padre y `Carro` y `Motocicleta` como clases hijas.

## Polimorfismo

El polimorfismo se aplica mediante el método `moverse()`. Las clases `Carro` y `Motocicleta` utilizan el mismo método, pero cada una presenta un comportamiento diferente.

## Encapsulamiento

El encapsulamiento se utiliza para proteger información de la clase. Para esto se emplea la propiedad privada `#kilometraje`, que solo puede ser consultada o modificada mediante métodos establecidos.

## Tecnologías

- JavaScript
- Programación Orientada a Objetos
- GitHub

## Objetivo

Comprender y aplicar los conceptos fundamentales de herencia, polimorfismo y encapsulamiento mediante un ejemplo práctico desarrollado en JavaScript.
